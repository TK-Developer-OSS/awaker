# ミックスの基本方針

## 順序

1. **レベル**（ゲインステージング → フェーダーのバランス）。
2. **不要な帯域を削る**（EQ のカット、HPF）。
3. **ダイナミクス**（コンプで飛び出す音を抑える）。
4. **足す**（EQ のブースト、空間系）。
5. **バス / マスター**は最後の仕上げ。

AI ミックス（平均スペクトル合わせ）は、`ai-mix` スキルに従う。

## 守る範囲

- 動かす量は小さく。フェーダーは ±3 dB ずつ、EQ は 1 手 ±3 dB（領域の `fix` に従う）。1 つの帯で合計 ±9 dB を超えない。
- EQ は、足すより削る。狭い帯のカットは Q 2〜4、広い補正は Q 0.7〜1。
- 低域に要らないもの（ギター、ボーカル、キーボードなど）には、ストリップの HPF（`hpfHz` 60〜120）。ベースとキックには掛けない。
- コンプの目安: `ratio` 2〜4、`attackMs` 10〜30（パンチを残す）、`releaseMs` 80〜200。潰しすぎ（`crestDb` が 6 dB 未満）にしない。
- マスターフェーダーはミックスの道具ではない。ヘッドルーム（ピーク -1 dBFS 以下、`clippedFrames` 0）のためだけに動かす。
- ラウドネス（-14 LUFS など）は、人が頼んだときだけ扱う。頼まれていなければ数値も目標にしない。
- 位相・ステレオ幅は、この版のツールでは測れない。測れないことを「直した」と言わない。

## 確かめ方

- `bounce`: `peakDb`、`rmsDb`、`lufsIntegrated`、`clippedFrames`。
- `track_levels`: トラックごとの `rmsDb` / `peakDb` / `stickOutDb`。
- `spectrum_analyze`: 曲全体の平均スペクトルと目標との差。
